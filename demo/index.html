02 / mechanics

One signal. Every layer.

The predecessor’s predicted feature is transferred in a unified embedding space, then refreshed after decoding.

Adjacent causal injection

live trace

All positions update in parallel. The dependency chain unfolds over depth: each column receives a gated message from its immediate predecessor before the next layer.

03 / quick start

Drop into SGLang.

Install the plugin, point it at the target and DSpine draft checkpoints, then serve with one command.

inference command

Python 3.10+, CUDA, and SGLang 0.5.20 are the supported baseline for the current release.

View repository ↗
# serve Qwen3-8B with the DSpine drafter
sglang serve \
  --model-path Qwen/Qwen3-8B \
  --speculative-algorithm DSPINE \
  --speculative-draft-model-path \
    tencent/Qwen3-8B-DSpine-b16 \
  --speculative-num-draft-tokens 16 \
  --tp-size 1 \
  --dtype bfloat16
